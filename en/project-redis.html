Mini Redis.

A lightweight in-memory key–value store inspired by Redis architecture.

In-memory key–value storage
01 / ARCHITECTURE

From a TCP server to a data store in Java

MiniRedis is an in-memory store I built in Core Java. Main loads the AOF file and starts the server on port 6379. MiniRedisServer passes TCP connections to a pool of 10 threads.

ClientHandler parses input and CommandFactory selects a command class. Each command operates on MiniRedisStore, which holds data in a ConcurrentHashMap.

02 / EXPIRING DATA

SETEX and TTL

SETEX stores a value with an expiry time. Expired entries are removed on GET or by a background scan every second. TTL returns the remaining seconds, −1 for a key without expiry, and −2 for a missing or expired key.

03 / PERSISTENCE AND COUNTERS

Writing memory changes to a file

SET and DEL operations are appended to miniredis.aof and replayed at startup. INCR and DECR update integer values through synchronized Java methods.

In this version, SETEX is logged as SET, so expiry times are not saved in the AOF file. Preserving expiry across restarts is a limitation of the current implementation.

04 / RUN LOCALLY

Try the actual application

Download the GitHub repository and run Main in a Java development environment. Once the server starts, connect with a Telnet client:

telnet localhost 6379
SET ad Hasan
GET ad
SETEX mesaj 15 selam
TTL mesaj
INCR ziyaretci_sayisi
INFO
QUIT
