01 / MİMARİ|01 / ARCHITECTURE
Java ile TCP sunucusundan veri deposuna|From a TCP server to a data store in Java
MiniRedis, Core Java ile geliştirdiğim bir bellek içi veri deposu. Main sınıfı AOF dosyasını yükleyip sunucuyu 6379 portunda başlatıyor. MiniRedisServer, gelen TCP bağlantılarını 10 iş parçacıklı bir havuza aktarıyor.|MiniRedis is an in-memory store I built in Core Java. Main loads the AOF file and starts the server on port 6379. MiniRedisServer passes TCP connections to a pool of 10 threads.
ClientHandler komutu ayrıştırıyor; CommandFactory ilgili komut sınıfını seçiyor. Her komut, veriyi ConcurrentHashMap içinde tutan MiniRedisStore üzerinde çalışıyor.|ClientHandler parses input and CommandFactory selects a command class. 02 / SÜRELİ VERİ|02 / EXPIRING DATA
SETEX ve TTL|SETEX and TTL
SETEX, değeri bir son kullanma zamanı ile kaydediyor. Süresi geçen kayıtlar GET sırasında veya saniyede bir çalışan arka plan taramasıyla temizleniyor. TTL kalan süreyi saniye olarak döndürüyor; süresiz kayıtta −1, bulunmayan veya süresi geçmiş kayıtta −2 veriyor.|SETEX stores a value with an expiry time. Expired entries are removed on GET or by a background scan every second. TTL returns the remaining seconds, −1 for a key without expiry, and −2 for a missing or expired key.
03 / KAYIT VE SAYAÇLAR|03 / PERSISTENCE AND COUNTERS
Bellekteki değişiklikleri dosyaya yazmak|Writing memory changes to a file
SET ve DEL işlemleri miniredis.aof dosyasına ekleniyor. Başlangıçta bu kayıtlar okunarak veri belleğe yükleniyor. INCR ve DECR, Java tarafında synchronized metotlarla tam sayı değerlerini değiştiriyor.|SET and DEL operations are appended to miniredis.aof and replayed at startup. INCR and DECR update integer values through synchronized Java methods.
Bu sürümde SETEX dosyaya SET olarak yazılıyor; son kullanma zamanı AOF içinde saklanmıyor. Yeniden başlatma sonrasında süre bilgisinin korunması, mevcut uygulamanın bir sınırlaması.|In this version, SETEX is logged as SET, so expiry times are not saved in the AOF file. Preserving expiry across restarts is a limitation of the current implementation.
